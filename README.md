# DevFinder 🔎

A modern GitHub developer explorer built with React, TypeScript and Tailwind CSS.

## 🌐 Live Demo

https://devfinder-fgoc.vercel.app/

## ✨ Features

- Search GitHub developers by username
- View developer profile information
- Followers, following and repository statistics
- Explore recent repositories
- Language analytics
- Sort repositories by recent updates, stars and forks
- Responsive modern UI
- GitHub API integration

## 🛠️ Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- Lucide React
- GitHub REST API
- Vercel
